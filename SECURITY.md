# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Please report security issues or vulnerability findings confidentially to the platform security team. Do not open public issues for zero-day security vulnerabilities.

### Disclosure Process
1. Contact the security team via security disclosure email.
2. Provide vulnerability reproduction steps and technical proof-of-concept.
3. Allow up to 30 days for patch deployment before public disclosure.
